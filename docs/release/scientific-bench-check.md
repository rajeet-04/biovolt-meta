# Scientific bench release checks

Before a measured release claim, record trusted multimeter checks for the precision load and ADS1115 reference, BPW34 dark/blank readings, 680 nm probe geometry/timing, and DS18B20/BH1750 plausibility comparisons. These are bench sanity checks, not laboratory certification. Until real references are recorded, use simulated values and keep biomass/CO2 claims unavailable or explicitly demonstrative.
